# 人物张力：目标、选择与后果

用于重要人物设计、关键关系场景、重大选择，或修改“人物只听剧情安排”的章节。目的是让人物选择牵动读者，不是复制某部作品的角色结构。

## 按场景选用，不套统一公式

先判断当前场景的功能：推进事件、改变关系、呈现日常、提供信息还是情绪缓冲。已有可信动机且符合功能的场景，不为增加张力而改写。

人物张力不只是“行为解释得通”，还包括读者在意的期待遇到阻力：希望人物得到什么、担心失去什么、想知道关系会怎样。可以来自选择、等待、误解或直接交流；不一定要制造两难或性格反转。先写清读者值得在意的目标与关系，再判断是否需要加强阻力。

先用既有行为和相处说明“这件事对这个人为何重要”，再分析选择。只有性格标签或目标清单不够：说一个人孤独，需要有相处或生活细节；说他珍惜一段关系，需要让读者看见那段关系带给他什么。相关背景已经写清时，无需重复补说明。

| 场景需求 | 可用方法 | 无需强加 |
|---|---|---|
| 忠诚与良知冲突 | 两个合理目标无法兼得，选择暴露底线 | 悲惨童年、隐藏身份 |
| 朋友争执 | 双方各有目标与信息，行动改变信任 | 谁必须撒谎或“外冷内热” |
| 久别重逢 | 想表达与实际表达之间的差距，用动作或对白显露 | 死亡、永久分离 |
| 日常吃饭、赶路、玩笑 | 习惯差异与自然互动；必要时轻微摩擦 | 每场揭露伤口、制造大转折 |
| 路人提供消息 | 清楚的目的、信息来源与可信反应 | 完整张力卡、成长弧线 |

## 五种可选人物手法：含义、用途与边界

“可选”指先确定人物和场景需要解决的问题，再选择有帮助的手法；可以只用一种，也可以完全不用。它不是 CLI 开关、完成配额或审稿合格条件。先问“他想保住什么、什么阻止了他、会怎样选择、之后发生什么”，不要先挑手法再硬补经历。

| 手法 | 具体含义 | 什么时候适合用 | 不应该怎样用 |
|---|---|---|---|
| 创伤 | 过去的伤害持续影响现在的判断与行动 | 需要解释已有角色为何特别害怕、回避或执着某件事，且设计或正文有依据 | 为了“有深度”临时添加悲惨童年；以一次经历解释所有行为 |
| 防御 | 人物为避免受伤采取的应对方式，如玩笑、沉默、控制或讨好；不等于临床诊断 | 已观察到他有需要却不愿直接暴露，需要通过行为理解其应对方式 | 把每种习惯都归因于创伤，或把合理协商和谨慎一律病理化 |
| 面具 | 对外呈现与真实想法存在差距；可以有意识，也可能是习惯，并不总是互相相反 | 这种差距会影响信任、沟通或选择，且有实际行为支撑 | 强迫人人“外冷内热”“装弱藏强”；把真实脆弱都说成伪装 |
| 人物镜像 | 两个人面对相似问题，却采取不同选择，形成主题上的对照 | 需要通过不同答案展开主题，且双方都有独立目标 | 复制身世、配对凑数，或让配角只负责证明主角正确 |
| 高压反差 | 压力使人物表现出平时不明显的一面，不一定是“隐藏的真我” | 关键选择已有铺垫，压力能合理解释其反应，让读者重新认识他 | 突然变性格、变能力后用“终于露出真实”补解释；认为压力一定会摘下面具 |

例如，坦诚且成长幸福的人想陪朋友完成演出，却已承诺同一天参加家人的重要活动。只要双方期待、时间限制与协商结果写得可信，就有张力，不必增加创伤或面具。先看能否调整安排；若可以，就写协商而非硬造两难。同样，平时守信的人在危险中仍然守信、却付出更大代价，也能动人，不必制造高压反差。

既有角色成立时，优先保留；只有确实需要解释或深化时才提出新设计，并按项目确认策略处理。作者文风包或参考解析提到某个手法，不构成为原创角色添加经历的授权。

“代价”包括时间、机会、面子、责任、信任或资源的取舍，不等于死亡或悲剧。解决矛盾、恢复信任和温暖结局都可以成立；后果需要与事件分量相称，不要求永远无法修复。

## 人物张力卡：按需填写

日常使用先回答五个问题即可：人物现在想要什么？另一方想要什么？阻力或分歧是什么？人物怎样行动或回应？这会改变什么？在现有章纲里用几句话写清即可。只有发现动机不清、行动突兀或关系没有后续时，再展开相关卡片字段。

重要人物先明确目标、底线和行动空间。只有需要深入设计时才使用完整卡片；不适用项可省略，未知项保留待定，不补造隐秘经历。

```markdown
# 人物张力卡
- 人物与适用阶段：
- 状态：建议 / 已确认（注明确认范围）
- 已有正文或用户决定的依据：
- 外在姿态：别人通常看到什么；可以与内心一致。
- 真实需要：想获得、维护或避免什么。
- 核心恐惧或阻力：没有明确恐惧时，填写现实阻力即可。
- 应对方式：直接表达、协商、玩笑、沉默、控制、讨好或回避；不必是面具。
- 冲突需求或责任：哪些合理目标在当前处境中无法同时保全。
- 可观察的日常表现：行为、说话习惯或物件如何支持上述判断。
- 改变行动的条件：新信息、压力或关系变化如何影响选择；也允许坚持原有原则。
- 取舍与代价：失去什么、得到什么，由谁承担。
- 变化与后续：会改变哪段关系或行动；也可维持稳定性格。
- 不确定项与备选解释：
```

不要把内心推断当成既定事实。“表现冷静”不自动等于“有意隐藏创伤”；不同解释先作为建议保留。心理动机应由已确认设计或正文行为支撑，不把心理学术语当作角色诊断。

## 场景张力卡：让矛盾发生在行动中

用于关键关系变化或有分量的选择。简单场景只记录目标与结果即可，不需要逐项填写，也不强制每章出现两难。

```markdown
# 场景张力卡
- 章节、场景与功能：
- 状态及依据：
- 本方当前目标：
- 对方独立目标、掌握的信息与底线：
- 想说却没说的话：可选；坦诚交流的场景可以不填。
- 冲突由什么产生：利益、责任、价值观、信息差或外部阻力。
- 此前铺垫：正文位置，或尚待安排且未发生的计划。
- 触发变化：什么事实或行动使回避、等待或协商不再足够。
- 可行选择及取舍：必要时比较，不人为删掉明显更合理的办法。
- 实际行动：角色做了什么，而不只是作者解释了什么。
- 即时结果与承担者：
- 后续影响或修复路径：影响下一次相处、责任、计划或资源的方式。
```

先铺可观察的习惯和需求，再让关键行动回应它们。高压不是自动“摘下面具”：人物可以坚持原有行为、变得更犹豫，或在新信息下改变；转折要有相应的铺垫。

关系双方都应有行动空间；配角不是为了主角的成长才理解、原谅或牺牲。可以有平淡互动和已解决的冲突，不要求所有关系始终紧绷。

## 卡片放在哪里，怎样更新

Skill 保存通用方法、空白模板和单独标明的教学案例，不保存某个原创项目的人物设定。填写后的卡片放在小说项目已有的 planning 区域，场景卡也可并入现有章纲；无需创建新数据库、修改 `.novel_policy.json` 或强制迁移旧文件。

把未确认设计与已确认设定分开标记，依照 `project-contract.md` 的事实优先级和项目接受策略确认。卡片不会因为被保存、被检索命中或被审稿引用就自动进入正式记忆。场景中的选择与后果实际写入并接受正文后，再更新相关人物状态；计划发生过的事与实际发生过的事分别记录。

只读取当前场景相关卡片。已有角色已成立时直接检查，不为补模板回改其经历。原作人物解析留作外部分析资料；单独标明来源的教学案例可以讲解具体场景，但不把其中的人物关系、身世或桥段变成通用规则或原创项目设定。

## 人物与因果审稿的检查标准

需要看性格与关系背景、简短原文怎样连接场景选择，以及怎样迁移到原创设计时，再读 [两个《龙族》教学案例](character-tension-examples.md)。案例含剧情信息，只用于理解方法，不默认加载到原创写作上下文，也不把原作人物或桥段复制进项目卡片。

在既定审稿节奏内按需要使用，不因此额外启动每章全角色审稿。主 Agent 或只读审稿 Agent 检查：

1. **动机与信息**：选择是否由角色的目标、知识和底线支撑？是否只为推进剧情突然改性格？
2. **冲突与铺垫**：重要两难是否来自可信处境？有无被无故排除的更合理办法？不要求场景一定有内在冲突。
3. **双方主动性**：另一方是否也有自己的目的和反应，而非只服务主角？
4. **取舍与后果**：重大行动是否改变关系、责任、资源或下一步行动？后果的消退或修复是否有交代？日常事件无需夸大代价。
5. **呈现**：对白、动作与细节是否支持内心解释？直接表达也可有效，不把潜台词或留白当作必选。

每条意见给出正文位置、相关依据、为什么影响可信度，以及最小修正建议。分清“已确认事实冲突”“依据不足或待补读”“创作偏好”；不要把缺少卡片、创伤、面具、镜像或悲剧结局当成失败条件。

重大剧情红队重点检查前置铺垫、可行替代办法和不可逆后果，不通过强行牺牲角色增加所谓深度。用户确认的结局、关系边界和有意留白优先；新的解释或改变仍按项目确认策略处理。

这些是模型阅读与判断的问题，不是已实现的自动数值门禁。脚本通过不代表人物有张力，模板齐全也不代表人物可信。
